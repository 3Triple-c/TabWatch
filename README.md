How to Install and Use the Chrome Extension (Unpacked)
Requirements

A desktop or laptop computer

Google Chrome browser

Installation Steps

Download the extension source code from GitHub as a ZIP file.

Extract (unzip) the downloaded file to a folder on your computer.

Open Google Chrome.

In the address bar, navigate to:
chrome://extensions/

Enable Developer mode using the toggle in the top-right corner of the page.

Click the Load unpacked button that appears in the top-left corner.

Select the extracted folder containing the extension files.

The extension will now appear in your list of installed extensions.

Usage

Open the Chrome tab where you want the extension to operate.

Click the extension icon from the Chrome toolbar.

Use the extension’s features on the currently active tab.
